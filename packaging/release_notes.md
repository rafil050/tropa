Клиент для собственных прокси-серверов на ядре Xray для Windows 10/11 (64-бит).

## Что нового в {VERSION}
- Исправлено: при запуске могло открыться несколько копий Tropa — несколько окон в панели задач и значков в трее. Теперь всегда работает одна копия, повторный запуск просто показывает её окно.

## Установка
1. Скачайте **Tropa-Setup-{VERSION}.exe** ниже и запустите. Права администратора не нужны, Python не нужен, ядро Xray уже внутри.
2. Установщик не подписан цифровой подписью, поэтому Windows может показать «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Скопируйте ссылку на сервер или подписку от своего провайдера, нажмите в Tropa **Ctrl+V** и большую кнопку питания.

Если Tropa уже установлена, просто запустите новый установщик: программа закроется сама, настройки и серверы сохранятся.

## Что умеет
- VLESS (REALITY, Vision), VMess, Trojan, Shadowsocks (включая 2022), SOCKS5, Hysteria2; транспорты TCP, WebSocket, gRPC, XHTTP, HTTPUpgrade, mKCP
- Подписки (в том числе Xray JSON) с трафиком и сроком действия
- Маршрутизация: всё через прокси / кроме российских сайтов / только свой список; блокировка рекламы
- Реальная проверка задержки серверов через ядро, системный прокси, трей, автозапуск
- Кнопки «Предложить идею» и «Сообщить об ошибке», уведомление о новых версиях

Идеи и ошибки — в [задачах](https://github.com/rafil050/tropa/issues/new/choose). Пожалуйста, не публикуйте там ссылки на свои серверы и ключи.

Tropa не продаёт серверы и не собирает данные. Установщик собран автоматически на GitHub Actions из исходников этой версии.
